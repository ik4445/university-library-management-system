# University Library Management System (LMS)

## 1. Project Description
The University Library Management System is a software engineering project designed to improve the management of university library operations.

The system will manage books, student memberships, book borrowing, returns, reservations, and overdue notifications.

It aims to replace manual records and outdated procedures with an organized and efficient digital system.

## 2. Project Objectives
- Manage library books and their availability.
- Maintain student and faculty membership records.
- Record book borrowing and returning transactions.
- Allow members to reserve books.
- Identify overdue books.
- Generate overdue notifications.
- Improve accuracy and efficiency in library operations.

## 3. Project Scope
The project includes:
- Book management
- Member management
- Borrowing and returning
- Book reservations
- Overdue book tracking
- Notification management
- Basic reports

The project focuses on requirements analysis, system modeling, interface prototyping, and project documentation. Complete software implementation is not included.

## 4. Assumptions
- Students and faculty members can register as library members.
- Every book has a unique identification number.
- Members must have valid membership to borrow books.
- Borrowing has a predefined return deadline.
- The library staff will manage book and member records.
- Users will have access to the system through computers.

## 5. Constraints
- Limited project development time.
- Limited financial resources.
- Limited availability of team members.
- The project does not include complete software implementation.
- The system requires computers and internet access for online operations.
